# README — GitHub Upload Guide v3.1

## English
This package contains the **Chinese Handwriting Practice v3.1 (中文練字紙)** web app.

### New in v3.1
- Fixed PDF loading issue on iPhone (jsPDF preloaded)
- Optimized for iPhone Safari (fixed jsPDF timeout issue)
- Added: Print, Page Orientation, Font Color Picker, Grid Style, Text Direction, Grid Fill Direction, OCR (Image → Text)
- Added: ± buttons for grid size & margin
- Improved: Mobile layout (iPhone-friendly)

### How to publish on GitHub Pages
1. Create or open your GitHub repository.
2. Upload all files (keep folder structure).
3. Go to **Settings → Pages → Source: Deploy from a branch → main → /(root)** → Save.
4. Wait ~30 seconds; your site will be live at `https://<username>.github.io/<repo-name>/`.

## 中文
此套件為 **中文練字紙 v3.1** 線上練字網站。

### v3.1 新增內容
- 修正 iPhone PDF 生成問題（預載 jsPDF）
- 已針對 iPhone Safari 優化（修正 jsPDF timeout 問題）
- 新增：列印、紙張方向、字體顏色、內線樣式、文字方向、格仔填滿方向、圖片 OCR
- 加入 ± 按鈕（方格大小及邊界）
- 改良 iPhone 顯示

### 發佈至 GitHub Pages
1. 建立或開啟 GitHub 儲存庫。
2. 上傳整個套件（保持原有結構）。
3. 前往 **Settings → Pages → Source: Deploy from a branch → main → /(root)** → Save。
4. 約 30 秒後即可在 `https://<你的帳號>.github.io/<repo-name>/` 瀏覽網站。
