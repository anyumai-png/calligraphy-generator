# README — GitHub Upload Guide v3.0

## English
This package contains a modern, bilingual web app: **中文練字紙 (Chinese Handwriting Practice)**.

### Files
- `index.html` — the app
- `assets/banner.png` — desktop banner (1200×300, PNG)
- `assets/banner_mobile.png` — mobile banner (800×200, PNG)
- `assets/favicon.ico` — 32×32 favicon
- `README.md` — this guide

### How to publish on GitHub Pages
1. Create / open your GitHub repository.
2. Upload all files and folders from this package (keep the structure).
3. Go to **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** → Folder: **/(root)** → **Save**.
4. Wait ~30 seconds; your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## 中文
這個套件是現代化的雙語網站：**中文練字紙 (Chinese Handwriting Practice)**。

### 檔案內容
- `index.html` — 網站主頁
- `assets/banner.png` — 桌面橫幅（1200×300，PNG）
- `assets/banner_mobile.png` — 行動裝置橫幅（800×200，PNG）
- `assets/favicon.ico` — 32×32 網站圖示
- `README.md` — 本指南

### 發佈到 GitHub Pages
1. 建立或開啟你的 GitHub 儲存庫。
2. 上傳整個套件內的所有檔案與資料夾（保持原有結構）。
3. 前往 **Settings → Pages** → Source 選 **Deploy from a branch** → Branch 選 **main** → Folder 選 **/(root)** → **Save**。
4. 約 30 秒後，網站將可於 `https://<你的帳號>.github.io/<repo-name>/` 造訪。
