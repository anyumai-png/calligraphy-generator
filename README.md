# 中文寫字練習紙生成器（GitHub Pages 版本）

## 發布步驟
1. 建立公開 repo（例如 `calligraphy-generator`）。
2. 上傳此資料夾全部檔案（含 `index.html` 與 `assets/`）。
3. 打開 `Settings → Pages`：選擇 **Deploy from a branch**；Branch 選 **main / root**。
4. 儲存後，網址會是 `https://<你的帳號>.github.io/calligraphy-generator/`。

> 可在 `index.html` 中插入 AdSense 代碼（通過審核後）。
